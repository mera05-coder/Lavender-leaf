🌿 Lavender Leaf
Your Path to Equilibrium & Health
📖 Description
Lavender Leaf is a lifestyle and fitness application designed to help users track their wellness journey. It provides a centered, easy-to-use interface to maintain your personal health and activity data.
✨ Key Features
• Workout Tracking: Log and monitor your physical activity to reach your fitness goals.
• Lifestyle Management: Tools designed to help you find your "Equilibrium 360".
• Custom Aesthetic: A clean interface featuring a White and Purple color palette for a calm user experience.
🛠 Technical Specifications
This project was developed by a student at Taibah University.
• Database Management: Structured using robust data handling and logic.
• UI/UX Design: Designed with a professional and modern aesthetic.
